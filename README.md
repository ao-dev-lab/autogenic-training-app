# 自律訓練法ガイド(試作版)

iPhoneのSafariで使える、自律訓練法(じりつくんれんほう)の日本語音声ガイドWebアプリです。

- 外部AI・外部APIは使用していません
- APIキーは不要です
- ブラウザに内蔵された音声読み上げ機能(Web Speech API)だけで動きます
- 5分・10分・15分のコースを選べます

## 使い方(初めての方向け)

1. `index.html` というファイルをiPhoneのSafariで開きます。
   - このリポジトリをGitHub Pagesなどで公開すれば、そのURLをSafariで開くだけで使えます。
   - 手元で試すだけなら、`index.html` をパソコンでダブルクリックしてブラウザで開いても動作を確認できます(音声合成はパソコンのブラウザでも動きます)。
2. 画面上部で「5分」「10分」「15分」のいずれかを選びます。
3. 大きな「開始」ボタンを押すと、音声での誘導が始まります。
4. 途中で止めたいときは「一時停止」ボタンを押します。もう一度押すと「再開」します。
5. 途中でやめたいときは「終了」ボタンを押します。

### うまく音が出ないときは

- iPhone本体の横にあるサイレント(マナーモード)スイッチがオンになっていないか確認してください。
- 音量が0になっていないか確認してください。
- 一部のブラウザは、ボタンを押すなどの操作が無いと音声を再生できない仕組みになっています。最初に「開始」ボタンを押すことで音声が有効になります。

## 内容の構成

1. 準備(楽な姿勢・落ち着き)
2. 重感練習(手足が重いという言葉かけ)
3. 温感練習(手足が温かいという言葉かけ)
4. 自然な呼吸
5. 消去動作(手を握る・伸びをするなど、最後に体をすっきりさせる動作)
